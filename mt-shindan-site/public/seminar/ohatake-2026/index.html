AIプロンプト集

大畠商工会 生成AI活用セミナー
～事業計画策定編～ 2026年11月17日

使い方

  • 【　】のところを、自分のことに入れ替えてから送信します。
  • ChatGPT・Geminiなど、ほかのAIでも同じように使えます。
  • 一回で気に入らなければ「もっと短く」「別の案を」と言い直してください。
  • 「コピーする」を押して、AIの入力欄に貼り付けます。

入れてはいけない3つ

  • お客様の名前・電話番号・住所・注文の中身
  • 従業員の給与・健康・家族のこと
  • 取引先との契約・見積の中身、パスワード

迷ったら「Aさん」「B社」に置き換えて入力します。Claudeは「設定 → プライバシー → AIモデルの改善に協力する」をオフにしておくと、入力した内容がAIの学習に使われません。

はじめに

①最初のひと言：自分の仕事を伝える

私は山口県柳井市で【業種】を営んでいます。
従業員は【人数】人、主なお客様は【客層】です。
これから仕事の相談をします。
まず、私の仕事でAIが手伝えそうなことを5つ、短く教えてください。

事業計画をつくる

②強みと課題の棚卸し（AIにインタビューしてもらう）

あなたは小規模事業者の相談にのる専門家です。
私の店（会社）の強みと課題を整理したいので、私にインタビューしてください。
質問は1つずつ、全部で5問。
最後に「強み」「課題」「お客様が選ぶ理由」を箇条書きでまとめてください。
業種は【業種】です。

答えは短くて大丈夫です。途中でやめたいときは「ここまででまとめてください」と送ります。

③計画書の下書き（②の会話の続きに送る）

ここまでの会話をもとに、持続化補助金の経営計画の「自社や自社の提供する商品・サービスの強み・弱み」の下書きを400字程度で書いてください。
条件：私が話していない事実や数字は書かない。足りない情報は【要確認：○○】と残す。

「強み・弱み」の部分を「経営方針・目標と今後のプラン」などに変えると、ほかの欄の下書きにも使えます。

市場の動向を調べる（出典つき）

【柳井市】の【飲食業】を取り巻く環境（人口の動き、観光客、物価など）を、国や自治体の公的な統計から調べてください。
要点を5つにまとめ、それぞれに出典の名前とURLを付けてください。
わからないことは、わからないと書いてください。

出典のURLを必ず開いて、数字がそこに書いてあるか自分の目で確かめてから使います。

④審査員の目で推敲させる

あなたは持続化補助金の審査員です。
上の下書きを読んで、①わかりにくい所 ②根拠が足りない所 ③もっと具体的に書くべき所 を合わせて5つ、厳しめに指摘してください。
直した文章は、まだ書かないでください。

直すのは自分です。指摘だけもらうと、自分の言葉の計画書になります。

計画書全体の抜けをチェックする

次の経営計画を読んで、「課題」「強み」「今後のプラン」「補助事業でやること」が一本の筋でつながっているか確認してください。
つながっていない所があれば、どこか・なぜかを教えてください。

（ここに計画書の文章を貼る）

毎日の書き仕事

⑤SNSの投稿文

私の店の強み【強み】を伝える投稿文を、Instagram（またはLINE・Facebook）用に3案作ってください。
条件：150字以内。地元のお客様に向けて、親しみやすく。最後にハッシュタグを3つ。

写真を1枚送って「この写真で投稿文を作って」でも作れます。

⑥言いにくいお知らせ（値上げ・臨時休業）

来年1月から、原材料の値上がりにより【商品】の価格を【旧価格】から【新価格】に改定します。
常連のお客様に向けて、店頭に貼るお知らせ文を作ってください。
条件：おわびと感謝が伝わるように。300字以内、やわらかい言葉で。

⑦見積書の送付文・お礼状・おわび

【取引先名】様に見積書をメールで送ります。送付文を作ってください。
内容：【工事名】の見積書を添付。有効期限は【日付】。不明点は電話で。
条件：丁寧だが短く、5行程度。

続けて「お礼状にして」「納期が遅れるおわびにして」と送ると、別の文章になります。

Googleマップの口コミに返信する

Googleマップに次の口コミが届きました。お店として返信する文を作ってください。
条件：お礼 → 具体的なひとこと → またのご来店を。200字以内。

口コミ：（ここに口コミの文章を貼る）

投稿した人の名前は貼らないでください。

⑧声で頼む（朝礼の原稿）

明日の朝礼で、【年末に向けて気をつけること】を3つ話したいです。1分で話せる原稿にしてください。

入力欄のマイクのボタンを押して、しゃべるだけで入力できます。

手書きのメモを表にする（写真を送る）

この写真の内容を表にして、Excelファイルで出してください。
読み取れない所は【？】と書いてください。

無料版は写真を送れる回数が少ないので、大事なときに使います。

メモを議事録・要点にまとめる

次のメモを、①決まったこと ②次にやること（誰が・いつまで） ③保留になったこと、の3つに分けて整理してください。

（ここにメモを貼る）

アイデア出し（10個 → 3つ → 計画へ）

【冬の集客】のアイデアを10個出してください。お金をかけずにできるものを中心に。

続けて送る（1）

その中で、うちの強みが生きるものを3つ選んで、理由も教えてください。

続けて送る（2）

1つめを、経営計画の「今後のプラン」に書ける形にしてください。

文章の言い回しを直す

次の文章を、【もっと丁寧に／もっと短く／やわらかく】直してください。意味は変えないでください。

（ここに文章を貼る）

困ったときの言い直しフレーズ

「もっと短く」長すぎるとき
「別の案を3つ」ピンとこないとき
「中学生にもわかる言葉で」難しいとき
「わからない時は、わからないと言って」最初に付けておくと、でたらめが減る
「私に質問してください。1つずつ。」何を頼めばいいかわからないとき

安全に使う5つのルール

  1. お客様・従業員の個人情報は入れない
  2. 取引先の秘密・パスワードは入れない
  3. 数字・日付・制度は、元の資料で確かめる
  4. AIの文章は、自分の言葉に直してから出す
  5. 他人の文章・写真・ロゴをまねさせない
