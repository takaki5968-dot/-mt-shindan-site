小さな会社やお店が新しいお客さんを開拓する費用の原則3分の2を、国が補助する「小規模事業者持続化補助金」。その第20回が、11月5日（木）に申請の受付を始めます。

申請の締切は12月15日（火）17時です。ただ、<strong>実際に動くべき締切は、その11日前の12月4日（金）</strong>です。商工会・商工会議所に「事業支援計画書（様式4）」を発行してもらう受付が、この日で締め切られるからです。

11月2日から数えると、12月4日までは5週間ほど。長いようですが、GビズIDを書類の郵送で申し込むと、それだけで最大1か月かかります。

私は独立する前、商工会で9年間働き、そのうち7年は経営指導員でした。持続化補助金の申請は、制度ができたころから今まで、ずっとお手伝いしてきています。

この記事では、持続化補助金がどんな制度かを確かめたうえで、申請から入金までの流れ、GビズIDの取り方、様式4の頼み方、必要書類、そして12月4日から逆算した準備をまとめます。

## 持続化補助金とは

小さな会社やお店が、売上を伸ばすために新しいお客さんを開拓する取り組み（販路開拓）にかかる費用の一部を、国が補助する制度です。正式な名前は「小規模事業者持続化補助金」といいます。自分で立てた経営計画にもとづく販路開拓と、それとあわせて行う業務の効率化が対象です。法人でも個人事業主でも申請できます。

| 項目 | 内容 |
| --- | --- |
| 対象になる事業者 | 従業員の数が、商業・サービス業（宿泊業・娯楽業を除く）は5人以下、宿泊業・娯楽業と製造業その他は20人以下 |
| 補助の上限 | 50万円。インボイス特例で＋50万円、賃金引上げ特例で＋150万円、両方なら＋200万円 |
| 補助率 | 費用の3分の2（賃金引上げ特例を使う赤字の事業者は4分の3） |
| 対象になる費用 | 機械装置等費、広報費、ウェブサイト関連費、展示会等出展費、旅費、新商品開発費、借料、委託・外注費 |

たとえば、新しい商品を知ってもらうためのチラシや広告（広報費）、ネットで売るためのホームページ（ウェブサイト関連費）、お客さんを迎えるための店舗の改装工事（委託・外注費）といった使い方です。75万円（税抜）をかけた場合、補助金は3分の2の50万円になります。

ただし、広報費とウェブサイト関連費は、それぞれ補助金で30万円までで、どちらもそれだけでは申請できません。ほかの経費と組み合わせる必要があります。第20回で変わったことは、[持続化補助金 第20回の変更点](/blog/jizokuka-dai20kai-2026/)にまとめています。

## 申請から入金までの流れ

まず全体の流れです。補助金が入るのは、申請からかなり先になります。

| 時期 | 何をするか |
| --- | --- |
| 11月5日（木） | 電子申請の受付開始 |
| 12月4日（金） | 様式4の発行受付の締切 |
| 12月15日（火）17時 | 申請の締切 |
| 2027年3月ごろ（予定） | 採択の発表 |
| 採択のあと | 見積書を出し、交付決定を受ける。交付決定は採択発表からおおむね1〜2か月 |
| 交付決定のあと | 発注・支払いをして、補助事業を行う。期限は2028年3月31日 |
| 事業が終わったら | 実績報告をして、補助金を請求する。そのあとに入金 |

<strong>補助金は後払いです。</strong>経費はいったん全額を自分で払い、事業を終えて実績報告をしたあとに補助金が入ります。また、交付決定より前に発注したり支払ったりしたものは、補助の対象になりません（展示会の出展申し込みだけは例外です）。採択の知らせが来ても、すぐには買えないということです。

## まず確かめたいのは、GビズIDプライム

申請は電子申請だけで、郵送では受け付けていません。電子申請には、GビズIDプライム（またはGビズIDメンバー）のアカウントが必要です。

取得にかかる日数は、申し込み方で大きく違います。

| 申し込み方 | 発行まで |
| --- | --- |
| マイナンバーカードとスマートフォンのアプリで申し込む（オンライン） | 最短で即日 |
| 書類を印刷して郵送する | 最大1か月 |

書類の郵送だと、12月4日に間に合うかどうかの瀬戸際です。オンラインで申し込むには、署名用電子証明書が有効なマイナンバーカードと、カードを読み取れるスマートフォンが要ります。法人の場合は、登記の情報とマイナンバーカードの情報が一致している必要があります。公募要領も、取得には「数週間程度」かかるとしています。持っていない方は、今日のうちに申し込んでください。

すでに持っている方も、住所や代表者が変わっているなら、申請の前に登録情報を新しくしておく必要があります。

GビズIDのパスワードを支援者に教えるのは、利用規約に反します。申請の操作は、ご自身で行うことになります。申請の連絡担当者も、代表者か従業員に限られます（よくある質問 A4-6）。

## 様式4の頼み方（商工会に入っていなくても大丈夫）

<strong>様式4は、商工会・商工会議所の会員でなくても発行してもらえます</strong>（よくある質問 A4-9）。様式4がないと申請できないので、会員かどうかにかかわらず、地域の商工会・商工会議所に相談してください。

頼み方は、どちらの地区かで少し違います。

| 地区 | 頼み方 |
| --- | --- |
| 商工会の地区 | 申請システムの中から商工会に発行を依頼し、窓口で面談を受けて発行してもらう |
| 商工会議所の地区 | 商工会議所に直接依頼し、発行された様式4のPDFを申請システムにアップロードする |

商工会の地区では、依頼そのものを申請システムから出します。システムが開く11月5日より前に、窓口に連絡して段取りを聞いておくと安心です。

商工会の経営指導員だったころは、私も様式4を書く側にいました。ただ、様式4そのものは、審査の対象には含まれていません。様式4がないと申請はできませんが、審査で見られるのは、事業者自身が書いた計画です。

公募要領には、発行には時間がかかる場合があるので余裕をもって依頼すること、受付締切のあとは理由を問わず発行できないことが書かれています。発行にあたって、代表者に計画の中身を直接確認する場合もあるとされています。

## 必要書類

申請書や計画書（様式1・2・3・5・6）は、申請システムに直接入力します。そのほかに添付する書類は、次のとおりです。

| 当てはまる人 | 添付する書類 |
| --- | --- |
| 全員 | 事業支援計画書（様式4）。商工会・商工会議所が発行 |
| 法人 | 直近1期分の貸借対照表と損益計算書。損益計算書がなければ、確定申告書の表紙と別表四 |
| 法人で、まだ決算を迎えていない | 売上台帳など。あわせて、現在事項全部証明書か履歴事項全部証明書（申請日から3か月以内の原本） |
| 個人事業主 | 直近の確定申告書（第一表・第二表と、収支内訳書または青色申告決算書） |
| 個人事業主で、まだ決算期を迎えていない | 開業届と売上台帳など。開業日の書かれていない開業届は無効 |
| インボイス特例を使う | 適格請求書発行事業者の登録通知書など。宣誓・同意はシステム上で行う |
| 賃金引上げ特例を使う赤字の法人 | 直近1期の法人税申告書の別表一・別表四。誓約・同意はシステム上で行う |
| 経営力向上計画の加点を希望する | 経営力向上計画の認定書 |
| 事業承継の加点を希望する | 事業承継診断票（様式10。様式4と同時に商工会・商工会議所に依頼）と、代表者の生年月日が分かる公的書類 |

書類にマイナンバーが書かれている場合は、番号が見えないように黒塗りします。特例や加点の要件は細かく決まっているので、使う予定の方は公募要領で確かめてください。

## 12月4日から逆算した、週ごとの段取り

次の表は、ひとつの目安です。

| 時期 | やること |
| --- | --- |
| 11月2日の週 | GビズIDの申し込み。商工会・商工会議所に連絡。決算書や確定申告書をそろえる |
| 11月9日の週 | 計画の骨子をつくる。誰に、何を、なぜ自分の店が、をはっきりさせる |
| 11月16日の週 | 経費の金額をつかむ。計画書を書き上げる |
| 11月23日の週 | 商工会・商工会議所で計画を見てもらい、様式4の発行を依頼する |
| 12月4日（金） | 様式4の発行受付の締切 |
| 12月15日（火）17時 | 申請の締切 |

なお、11月24日（火）20時から25日（水）1時ごろまで、GビズIDはメンテナンスで使えなくなります。様式4の依頼や申請の作業は、この時間を避けてください。

経費の欄には、申請の段階で金額を書きます。ただ、見積書そのものを出すのは採択のあとです。そのときは、1件あたり税込50万円を超える発注について、2者以上から見積を取る必要があります。今のうちに、だいたいの金額と頼む先の当たりをつけておくと、あとが楽です。

計画書をAIの手を借りて書く場合の注意は、[持続化補助金は自分で書ける？AIで申請書を作る前に知っておくこと](/blog/jizokuka-self-application-ai/)にまとめています。

## 10月22日に公開された資料

事務局のサイトでは、10月22日に「よくあるご質問（第20回公募）」が公開され、参考資料と、賃金引上げ特例・加点の要件達成シートが差し替えられました。10月23日には、賃金引上げ特例・加点の説明動画も公開されています。

よくある質問の中で、見落としやすいのが、商工会・商工会議所以外の人から助言を受けた場合の書き方です。お金を払っていなくても、助言した人の名前を書き、金額の欄は0円と入力します。成功報酬を後払いで払う約束なら、払う予定の額を書きます（A4-11）。

賃金引上げ特例を使う予定の方は、差し替え後の要件達成シートを使ってください。差し替え前のものを使っていないか、一度確かめておくと安心です。

## 本当に大変なのは、採択されたあと

申請の準備をしていると、採択されることがゴールのように思えてきます。ただ、制度ができたころから申請のお手伝いを続けてきて思うのは、大変なのはむしろ採択されたあとだということです。

採択されたら、計画に書いたとおりに事業を進めます。見積書を出して交付決定を受け、発注し、支払い、実績報告をします。補助の対象になるのは、使い道がはっきりしていて、交付決定のあとに発生し、期間中に支払いが済み、証拠の書類で支払った金額が確かめられる経費だけです。

公募要領には、対象外の経費が見つかればそれを除いて計算し直すこと、実績報告で要件を満たしていないと認められれば、補助金が交付決定の額より少なくなる場合があることが書かれています。<strong>交付申請や実績報告の書類に不備があって、補助金が減ってしまう例は、実際にあります。</strong>

以前あったのは、店舗の内装工事の見積書に「諸経費」という項目が入っていたケースです。公募要領では、「諸経費」のように内訳の分からない費用は、補助の対象外とされています。ただ、諸経費は工事業者がふだんから見積書に入れている項目なので、そのまま進めてしまい、その分が減額になるパターンがあります。

公募要領は、この補助金のルールブックです。何が対象で、何が対象外か。いつまでに何を出すか。答えは、ほとんど公募要領に書いてあります。支援者の手を借りる場合でも、申請するのは事業者自身です。<strong>公募要領を自分で読んで、確かめてから申請してください。</strong>

## まとめにかえて

申請の締切は12月15日。でも、準備の締切は12月4日です。

5週間あれば、間に合います。ただ、GビズIDを郵送で申し込めば最大1か月かかり、商工会・商工会議所とのやりとりにも時間がかかります。最初の週にやることは、GビズIDの申し込みと、商工会・商工会議所への連絡の2つです。それさえ済めば、残りの4週間を計画づくりに使えます。

そして、採択はゴールではなく、スタートです。採択のあとの手続きまで見据えて、公募要領を手元に置いておいてください。

当事務所では、計画づくりの最初からのご相談のほか、前回申請して不採択だった方の再申請のご相談や、ご自身で書いた計画書の最後の確認だけ、というご依頼も受け付けています。

（日程と要件は、事務局サイトとGビズIDの公式サイト（いずれも2026年11月1日確認）、公募要領 第8版（2026年7月21日改定）、よくあるご質問（2026年10月22日公開）によります。予定は変更される場合があります。）
