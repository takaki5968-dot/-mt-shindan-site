新しく仕入れた美容液のPOPを書こうとして、ペンが止まる。本当は「シミが薄くなる」と書きたい。お客さまにいちばん伝えたいのは、そこだからです。でも、それを書いたら違反になると聞いたことがある。じゃあ、何を書けばいいのか。

化粧品やエステサロンの事業者さんから、こうした悩みをよく伺います。

先に結論を書きます。<strong>言えないことは確かに多い。でも、ルールの範囲で伝えられることも、ちゃんとあります。</strong>そして、違反の処分は大手だけの話ではありません。2026年3月には、予約サイトのクーポンの書き方をめぐって、エステサロンの運営会社3社が消費者庁から措置命令を受けています。

## まず3問。どっちなら書ける？

ルールの説明に入る前に、3問だけ考えてみてください。

### 第1問　化粧品の広告で、書けるのはどっち？

- A：細胞から生まれ変わる
- B：角質層へ浸透

答えはBです。業界のガイドラインでは、化粧品で「浸透」と言えるのは角質層の範囲までで、そのことをはっきり書く必要があります。「肌へ浸透」だけだと範囲が分からないのでNG、「肌の奥深く」もNGです。「再生」は医薬品に使う言葉なので、化粧品では使えません。

### 第2問　敏感肌向けの化粧水。書けるのはどっち？

- A：敏感肌でも絶対安心
- B：皮膚刺激性テスト済み（全ての方に皮膚刺激が発生しないということではありません）

答えはBです。国の広告の基準では、効き目や安全性を保証する言い方は禁止されていて、「絶対安全」のような言い方も使えません。テストをしたという事実なら書けますが、条件があります。キャッチフレーズにしないこと、括弧の中のような注意書きを、すぐ近くに同じくらいの大きさで書くことです。

### 第3問　予約サイトのクーポン。これは大丈夫？

クーポンに「有効期限：12月末まで」と書いた。年が明けても、同じ割引をそのまま続けた。

答えは、アウトです。期限までに申し込まないと割引が受けられないかのように見せた、という扱いになります。2026年3月、エステサロンの運営会社3社が、ホットペッパービューティーのクーポンでまさにこの表示をして、消費者庁から措置命令を受けました。

第1問と第2問は、日本化粧品工業会の「化粧品等の適正広告ガイドライン」と、厚生労働省の「医薬品等適正広告基準」に、第3問は消費者庁の措置命令にもとづいています。

3問とも、ルールを知っていれば迷わない話です。ただ、知らないまま書いてしまう例が、実際に処分につながっています。

## 小さなお店も、実際に処分されている

「処分されるのは大手だけでしょう」と思われがちですが、そうではありません。

第3問のクーポンのほかにも、Googleマップに高評価の口コミを書いてくれたら割引する、という内科クリニックが、2024年に消費者庁から措置命令を受けています。ステルスマーケティングの規制で初めての処分でした。2025年には、星5の口コミと引き換えにQUOカードを渡していた歯科医院も処分されています。店頭の体験会で、スタッフの説明や掲示物が問題になった例もあります。

東京都の調査でも、化粧品・医薬部外品の「シミ・シワ」に関する広告は毎年チェックされています（[東京都 令和7年度調査](https://www.shouhiseikatu.metro.tokyo.lg.jp/chousa/t_chosain/documents/r7b3_kekka.pdf)）。

## 関わるルールは4つ

化粧品・エステの広告には、主に次の4つの法律が関わります。

| 法律 | 主な対象 | ひとことで言うと |
| --- | --- | --- |
| 薬機法 | 化粧品・医薬部外品・美顔器など | 認められた効能の範囲を超えて言ってはいけない |
| 景品表示法 | すべての商品・サービス（エステも） | 実際より良く・お得に見せてはいけない |
| 医師法 | エステの施術内容 | 医療行為にあたることを、やる・うたうのはNG |
| 特定商取引法 | 長期・高額のエステ契約、通販 | 契約や勧誘、表示のルールを守る |

薬機法の広告規制は「何人も」が対象で、メーカーだけでなく、販売店や、ブログやSNSで紹介する個人も含まれます。景品表示法も、商品やサービスを提供するすべての事業者が対象です。規模による例外はなく、個人サロンのInstagram、ホームページ、チラシ、店頭のPOPも広告として扱われます。

一般に、次の3つがそろうと広告とみなされます。

1. お客様に買ってもらおう、来てもらおうという意図がある
2. 商品名やサービス名がわかる
3. 一般の人が見られる状態にある

### 薬機法：化粧品で言えるのは「56項目」の範囲

化粧品で広告できる効能は、厚生労働省の通知で定められた56項目の範囲に限られます（メーキャップ効果や使用感は別）。「治る」「再生」「デトックス」などは、医薬品のような表現として使えません。

たとえば「シワが消える」はNGですが、「乾燥による小じわを目立たなくする」は、効能評価試験を済ませていれば通知の範囲内として使えます（[静岡県 違反事例資料](https://www.pref.shizuoka.jp/_res/projects/default_project/_page_/001/025/361/ihanjirei66.pdf)）。

同じスキンケア商品でも、分類によって言える効能が変わります。分類は、パッケージの「医薬部外品」「薬用」の表記で確認できます。

| 分類 | 言える範囲 | 例 |
| --- | --- | --- |
| 化粧品 | 通知で定められた56項目の範囲 | 肌にうるおいを与える、肌を整える |
| 医薬部外品（薬用化粧品） | 国に承認された効能の範囲 | メラニンの生成を抑え、シミ・そばかすを防ぐ（美白の承認がある場合） |

医薬部外品でも「シミが消える」「シワがなくなる」は承認の範囲を超えるためNGです。仕入れて販売する場合は、メーカーに承認された効能を確かめてから表現を決めましょう。

### 景品表示法：「盛る」「お得に見せる」がアウト

品質を実際より良く見せる「優良誤認」、価格や条件をお得に見せる「有利誤認」が禁止です。2023年10月からは、広告であることを隠す「ステルスマーケティング」も違反になりました。

「No.1」の表示も、厳しく見られるようになりました。消費者庁は2024年9月に「No.1表示に関する実態調査報告書」を公表し、No.1と言える根拠の条件として、比較する商品と調査対象者が適切に選ばれていること、調査が公平な方法で行われていること、表示と調査結果がきちんと対応していることを示しています（[BUSINESS LAWYERS](https://www.businesslawyers.jp/practices/153)）。商品を使ったことのない人にサイトの印象だけを聞く「イメージ調査」で「満足度No.1」とうたう手法には、措置命令が相次ぎました。調査会社に頼んだ結果でも、責任を負うのは広告主です。

受賞歴そのものは、事実なら表示できます。ただし、いつ・どの団体の・何の部門の賞かを明記し、何年も前の受賞を今の評価のように見せないことが必要です。

### 医師法と特定商取引法

エステは医療機関ではないため、医療行為にあたる施術はできず、広告でも医療的な効果はうたえません。脱毛では「永久脱毛」のような表現が典型的なNGです。

一定の期間・金額を超えるエステ契約は「特定継続的役務提供」として、書面の交付やクーリング・オフなどのルールがあります。誇大な勧誘や広告で、業務停止命令を受けた例もあります。

## 違反すると、どうなる？

「注意されて終わり」ではありません。お金、社名の公表、刑事罰まで用意されています。

| 法律 | 処分・罰則 | 内容 |
| --- | --- | --- |
| 薬機法 | 課徴金納付命令（2021年8月〜） | 違反期間の対象商品の売上の4.5％。景品表示法と違い、「相当の注意を怠っていなかった」ことを理由にした免除はない |
| 薬機法 | 措置命令 | 違反行為の中止、再発防止策、公表など |
| 薬機法 | 刑事罰（誇大広告） | 2年以下の拘禁刑（旧・懲役）または200万円以下の罰金（併科あり） |
| 景品表示法 | 措置命令 | 誤認の排除、再発防止策、社名の公表 |
| 景品表示法 | 課徴金納付命令 | 対象商品の売上の3％。10年以内の再違反は1.5倍（4.5％） |
| 景品表示法 | 直罰（2024年10月〜） | 故意の優良誤認・有利誤認は、措置命令を経ずに100万円以下の罰金 |

薬機法の課徴金は、課徴金額が225万円（対象売上でいえば5,000万円）未満なら命じられない仕組みです（[薬機法 第75条の5の2](https://laws.e-gov.go.jp/law/335AC0000000145)）。とはいえ、小さな事業者でも、措置命令による公表だけで信用は大きく傷つきます。

景品表示法には「不実証広告規制」もあります。消費者庁から表示の根拠資料を求められ、期間内に合理的な根拠を出せないと、それだけで不当表示とみなされます。「効果があるのは本当だから大丈夫」ではなく、<strong>根拠を出せるか</strong>が問われるのです。2024年10月の改正では、悪質なケースに直罰が新設され、法人の業務で行えば法人にも罰金が科されます（[DIME](https://dime.jp/genre/1888273/)）。

## SNS・口コミ・ビフォーアフター写真

小さなお店が一番つまずきやすいのが、日々のSNS発信と、お客さまの声の扱いです。

### 自分のお店のSNS投稿も「広告」

自社アカウントでの商品紹介や施術紹介は、日常の投稿のように見えても広告です。「この美容液でシミが消えました」と書けば、チラシに書くのと同じく違反になり得ます。

### お客さまの声は「感想」まで

お客さまの声を載せること自体はできます。ただし、効果を保証するような体験談はNGで、使用感や満足感の範囲にとどめます。

- OKの例：香りが好きで、毎晩のお手入れが楽しみになりました
- NGの例：2週間でシミが薄くなりました

お客さまが書いた言葉でも、お店が選んで載せれば、お店の広告として扱われます。

### 口コミのお願いを、特典と引き換えにしない

「星5の口コミで割引」「投稿でプレゼント」は、先ほどの医院のように、ステマとして措置命令が出ています。モニターやインフルエンサーに投稿を頼む場合は「PR」「広告」をはっきり示し、自社サイトに転載するときも、その表示が見える状態にします。

### ビフォーアフター写真は、条件つき

比較写真そのものが、すべて禁止されているわけではありません。工業会のガイドラインでは、乾燥した肌と保湿した肌の比較のように、化粧品に認められた効能の範囲の写真なら、原則として使えるとしています。

ただし、認められた範囲を超える効果を連想させる写真、効果が出るまでの時間や続く時間を保証する写真、安全性を保証する写真は使えません。「シミが薄くなった」ことを見せる比較写真は、化粧品の効能の範囲を超えるのでNGです。比較に使う写真は、同じ条件で撮り、加工していないことが前提です。エステの施術の比較写真も、効果を実際より良く見せれば景品表示法の問題になります。迷ったら載せないのが安全です。

AIで作った画像を広告に使うときも、考え方は同じです。実物より良く見せれば、作り方に関係なく問題になります（[AIで作ったPOPを使う前に](/blog/ai-generated-pop-caution/)）。

## 大手と同じ言葉なら、安全？

「大手の化粧品会社がこう書いているから、うちも同じでいいのでは」。これも、よくある考え方です。答えは、参考にするのはアリ、そのまま借りるのはナシ。理由は3つあります。

一つめは、大手は「言える裏付け」を持っていることです。大手の表現は、配合成分や効能評価試験、承認内容などの裏付けがあって、初めて言えているものが多いのです。「乾燥による小じわを目立たなくする」は効能評価試験を行った化粧品だから、「美白」は承認を受けた医薬部外品だから、「No.1」は調査結果があるから言えています。同じ言葉を自分の店の商品に使っても、裏付けがなければ違反です。

二つめは、大手でも処分されていることです。ステマ規制では、大正製薬やロート製薬、RIZAPグループの「chocoZAP」も措置命令を受けています（[宣伝会議 AdverTimes](https://www.advertimes.com/?p=480455)）。ロート製薬の件は、モニターに頼んだInstagramの投稿を「#PR」の表示なしで自社サイトに載せていたものでした（[AdverTimes](https://www.advertimes.com/20250327/article493369/)）。大手の表現が、たまたま見逃されているだけ、という可能性もあります。

三つめは、言葉そのものの問題です。キャッチコピーは短いため、著作物と認められないことが多く、英会話教材のキャッチフレーズが酷似していても著作物性が否定された裁判があります（スピードラーニング事件、[Web担当者Forum](https://webtan.impress.co.jp/e/2019/03/13/31768)）。一方で、交通標語「ボク安心 ママの膝より チャイルドシート」は著作物性が認められました（東京地裁 平成13年5月30日判決）。短いから大丈夫、とは言い切れません。

マネしてよいのは、言葉ではなく組み立て方です。誰の、どんな悩みに向けて書いているか。効果ではなく、使う場面や気持ちをどう描いているか。成分やこだわり、作り手の想いをどう伝えているか。そこを参考にしてください。

## 言えないなら、何を書くか

効果を言えないなら、効果以外で選ばれる理由をつくる。<strong>これが小さなお店の勝ち筋です。</strong>

言いたくなる表現と、言い換えの方向性をまとめます。

| 言いたくなる表現 | 言い換えの方向性 |
| --- | --- |
| シミが消える、シミが薄くなる | （化粧品）肌にうるおいを与えキメを整える／（美白の医薬部外品）メラニンの生成を抑え、シミ・そばかすを防ぐ |
| シワがなくなる、シワが改善する | （効能評価試験済みの化粧品）乾燥による小じわを目立たなくする |
| 若返る、-10歳肌、アンチエイジング | 年齢に応じたお手入れ、エイジングケア（年齢に応じたケアの意味と明記） |
| たるみが引き上がる、リフトアップ | 肌にハリを与える |
| ニキビが治る | （化粧品）肌荒れを防ぐ、皮膚をすこやかに保つ |
| 毛穴が消える | （洗顔料など）汚れをおとして皮膚を清浄にする、肌をひきしめる |
| 細胞から生まれ変わる、肌再生 | 角質層へ浸透（角質層の範囲と明記）、肌を整える |
| 敏感肌でも絶対安心、副作用なし | 皮膚刺激性テスト済み（全ての方に皮膚刺激が発生しないということではありません。注記は近くに同じくらいの大きさで） |
| 痩せる、脂肪が燃える、サイズダウン確実 | リラックスできる時間、ボディラインを意識したケア、丁寧なカウンセリング |
| 小顔になる | フェイスラインを意識したマッサージ |
| 永久脱毛、二度と生えない | ムダ毛のお手入れ、通う回数の目安、スタッフの研修体制 |
| 医師も推薦、医療レベル | 原料・成分へのこだわり、作り手の経歴 |
| 期間限定（実は常時） | 本当に期限を決めて実施し、期限後は戻す |

どの言い換えも、商品の分類や試験の有無で使えるかどうかが変わります。最終的には、商品ごとに確かめてください。

言い換え以上に効くのが、「言える土俵」で勝負することです。

1. 作り手・施術者の想いとストーリー
2. 原料・成分へのこだわり（効果ではなく、選んだ理由として）
3. 使い心地、香り、テクスチャーなどの使用感
4. お店の雰囲気、接客、通いやすさ
5. お客さまの声（感想の範囲で、効果を保証しない。特典と引き換えの依頼はしない）

化粧品の表現で迷ったときは、日本化粧品工業会の「化粧品等の適正広告ガイドライン」に、使える例と使えない例が具体的に載っています。エステ業界には、日本エステティック振興協議会の「エステティックの広告表記に関するガイドライン」もあります（[消費者委員会 資料](https://www.cao.go.jp/consumer/iinkai/2024/426/doc/20240318_shiryou2-1.pdf)）。

## 迷ったときの相談先

| 相談先 | 相談できること |
| --- | --- |
| 都道府県の薬務課 | 化粧品・医薬部外品の広告表現が薬機法の範囲内か |
| 都道府県の景品表示法担当課・消費生活センター | 価格表示、キャンペーン、No.1表示などが景品表示法に触れないか |
| 消費者庁 表示対策課 | 景品表示法の考え方全般 |
| 商工会・商工会議所 | 規制を踏まえた売り方、販促物、ホームページの見直し |
| 弁護士 | 具体的な表現の適否や、指導を受けたときの対応 |

行政の窓口は、広告を出す前の事前相談にも応じています。原稿と商品の資料（成分、承認内容、試験結果など）を用意すると、話が早く進みます。

## まとめにかえて

冒頭のPOPに戻ります。

「シミが薄くなる」とは書けません。でも、なぜこの美容液を選んで仕入れたのか、使ったときの香りや肌ざわり、お客さまにどんなふうに使ってほしいのか。これは書けます。大手の言葉を借りても、裏付けがなければ使えません。お店の人にしか書けない言葉のほうが、むしろ強いはずです。

予約サイトのクーポンも、Googleマップの口コミのお願いも、広告として見られています。迷ったら、書く前に一度確かめる。その手間が、お店の信用を守ります。

広告の言葉に迷ったら、ひとりで抱え込まずにご相談ください。表現の見直しや、言える範囲での魅力の伝え方を、一緒に考えます。
